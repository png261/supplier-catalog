| 6 | Gitleaks Scan | Synthetic test credentials inside allowlisted directory (`mock_data/` or `test/testutil/fixtures/`) | Allowlist rule matches path; Gitleaks bypasses fixture without flagging false positive. |
| 7 | Coverage Enforcement | `coverage.out` statement coverage is exactly 93.5% | `scripts/check-coverage.sh` extracts 93.5%, compares $93.5 \ge 90.0$ via `awk`, outputs green PASS banner, exits code 0. Push allowed. |

### 3.3 `.husky/pre-commit`
**Location**: `/Users/png/01. Project/coderpush/.husky/pre-commit`  
**Permissions**: Executable (`chmod +x .husky/pre-commit`)  
**Purpose**: Pre-commit hook enforcing staged secret scans, strict `gofmt`, `go vet ./...`, and `golangci-lint` (gracefully handled).

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=================================================="
echo " 🔒 Running Pre-Commit Security & Quality Gates"
echo "=================================================="

# 1. Gitleaks Secret Detection on Staged Files
if command -v gitleaks >/dev/null 2>&1; then
    echo "🔍 [1/4] Running Gitleaks staged secret scan..."
    if [ -f ".gitleaks.toml" ]; then
        gitleaks protect --staged -v --redact --config .gitleaks.toml
    else
        gitleaks protect --staged -v --redact
    fi
    echo "✅ Gitleaks staged scan passed (0 secrets detected)."
else
    echo "⚠️  [1/4] gitleaks is not installed in PATH."
    echo "    To install: brew install gitleaks (macOS) or visit https://github.com/gitleaks/gitleaks"
fi

# 2. Strict gofmt Verification
echo "🎨 [2/4] Verifying Go code formatting (gofmt)..."
STAGED_GO_FILES=$(git diff --cached --name-only --diff-filter=d | grep '\.go$' || true)
if [ -n "$STAGED_GO_FILES" ]; then
    UNFORMATTED=$(gofmt -l $STAGED_GO_FILES)
    if [ -n "$UNFORMATTED" ]; then
        echo "❌ ERROR: The following staged Go files are not properly formatted:" >&2
        echo "$UNFORMATTED" >&2
        echo "" >&2
        echo "To remediate, run:" >&2
        echo "  gofmt -w $UNFORMATTED" >&2
        echo "Then stage the changes (git add) and commit again." >&2
        exit 1
    fi
    echo "✅ All staged Go files are properly formatted."
else
    echo "ℹ️  No Go files staged for commit. Skipping gofmt."
fi

# 3. go vet Verification
echo "🩺 [3/4] Running compiler static analysis (go vet ./...)..."
if [ -n "$STAGED_GO_FILES" ]; then
    go vet ./...
    echo "✅ go vet passed with 0 issues."
else
    echo "ℹ️  No Go files staged for commit. Skipping go vet."
fi

# 4. golangci-lint Verification (Graceful handling)
echo "🧹 [4/4] Checking linter (golangci-lint)..."
if command -v golangci-lint >/dev/null 2>&1; then
    golangci-lint run ./...
    echo "✅ golangci-lint passed with 0 issues."
else
    echo "ℹ️  golangci-lint is not installed locally (skipping)."
    echo "    Recommended: brew install golangci-lint (macOS). CI enforces strict linting."
fi

echo "=================================================="
echo "🎉 All Pre-Commit gates passed! Proceeding with commit."
echo "=================================================="
exit 0
```

### 3.4 `scripts/check-coverage.sh`
**Location**: `/Users/png/01. Project/coderpush/scripts/check-coverage.sh`  
**Permissions**: Executable (`chmod +x scripts/check-coverage.sh`)  
**Purpose**: Portable POSIX-compliant shell script parsing statement coverage from Go coverprofiles and verifying $\ge 90.0\%$ threshold with floating point precision without external dependencies like `bc`.

```bash
#!/usr/bin/env bash
set -euo pipefail

# scripts/check-coverage.sh
# Verifies that total statement coverage in a Go coverprofile meets or exceeds a target threshold.
#
# Usage:
#   ./scripts/check-coverage.sh [profile_path] [min_threshold]
#   Example: ./scripts/check-coverage.sh coverage.out 90.0

PROFILE="${1:-coverage.out}"
THRESHOLD="${2:-90.0}"

if [ ! -f "$PROFILE" ]; then
    echo "❌ Error: Coverage profile '$PROFILE' does not exist." >&2
    echo "Generate it first using: go test -coverprofile=$PROFILE ./..." >&2
    exit 1
fi

TOTAL_LINE=$(go tool cover -func="$PROFILE" | grep "^total:" || true)
if [ -z "$TOTAL_LINE" ]; then
    echo "❌ Error: Could not parse total statements line from '$PROFILE'." >&2
    exit 1
fi

# Extract coverage percentage (e.g., '93.5%' -> '93.5')
COVERAGE=$(echo "$TOTAL_LINE" | awk '{print $NF}' | tr -d '%')

if [ -z "$COVERAGE" ]; then
    echo "❌ Error: Extracted empty coverage value from '$PROFILE'." >&2
    exit 1
fi

echo "=================================================="
echo " Coverage Gate Verification"
echo " Profile:   $PROFILE"
echo " Reported:  ${COVERAGE}%"
echo " Threshold: ${THRESHOLD}%"
echo "=================================================="

# Perform float comparison using awk (POSIX compliant, no bc dependency)
PASS=$(awk -v cov="$COVERAGE" -v min="$THRESHOLD" 'BEGIN { if (cov + 0.0 >= min + 0.0) print 1; else print 0 }')

if [ "$PASS" -eq 1 ]; then
    echo "✅ PASS: Statement coverage (${COVERAGE}%) meets or exceeds threshold (${THRESHOLD}%)."
    exit 0
else
    echo "❌ FAIL: Statement coverage (${COVERAGE}%) is BELOW required threshold (${THRESHOLD}%)." >&2
    exit 1
fi
```

### 3.5 `.husky/pre-push`
**Location**: `/Users/png/01. Project/coderpush/.husky/pre-push`  
**Permissions**: Executable (`chmod +x .husky/pre-push`)  
**Purpose**: Pre-push hook enforcing Gitleaks repository history scan, multi-iteration race testing (`go test -race -count=5 ./...`), and statement coverage threshold verification ($\ge 90.0\%$).

```bash
#!/usr/bin/env bash
set -euo pipefail

echo "=================================================="
echo " 🚀 Running Pre-Push Quality & Security Gates"
echo "=================================================="

# 1. Gitleaks Repository Scan
if command -v gitleaks >/dev/null 2>&1; then
    echo "🔍 [1/3] Running Gitleaks repository history scan..."
    if [ -f ".gitleaks.toml" ]; then
        gitleaks detect -v --redact --config .gitleaks.toml
    else
        gitleaks detect -v --redact
    fi
    echo "✅ Gitleaks scan passed with 0 detected secrets."
else
    echo "⚠️  [1/3] gitleaks not installed locally; skipping pre-push repo scan."
fi

# 2. Race condition detection and multi-iteration test execution
echo "🧪 [2/3] Executing multi-iteration race tests (go test -race -count=5 ./...)..."
COVERAGE_FILE="coverage.out"
go test -race -count=5 -covermode=atomic -coverprofile="$COVERAGE_FILE" ./...
echo "✅ All tests passed with 0 race conditions across 5 iterations."

# 3. Statement coverage verification (>= 90.0%)
echo "📊 [3/3] Enforcing statement coverage threshold (>= 90.0%)..."
REPO_ROOT="$(git rev-parse --show-toplevel 2>/dev/null || pwd)"
if [ -x "$REPO_ROOT/scripts/check-coverage.sh" ]; then
    "$REPO_ROOT/scripts/check-coverage.sh" "$COVERAGE_FILE" 90.0
else
    # Inlined POSIX coverage calculation fallback
    TOTAL_LINE=$(go tool cover -func="$COVERAGE_FILE" | grep "^total:" || true)
    COVERAGE=$(echo "$TOTAL_LINE" | awk '{print $NF}' | tr -d '%')
    echo "Reported Coverage: ${COVERAGE}% (Threshold: 90.0%)"
    PASS=$(awk -v cov="$COVERAGE" -v min="90.0" 'BEGIN { if (cov + 0.0 >= min + 0.0) print 1; else print 0 }')
    if [ "$PASS" -ne 1 ]; then
        echo "❌ Statement coverage (${COVERAGE}%) is below required 90.0%!" >&2
        exit 1
    fi
    echo "✅ Statement coverage (${COVERAGE}%) meets threshold 90.0%."
fi

echo "=================================================="
echo "🎉 All Pre-Push gates passed successfully! Push allowed."
echo "=================================================="
exit 0
```

### 2. Logic Chain
1. *Requirement R1* in `ORIGINAL_REQUEST.md` and `DISPATCH.md` demands:
   - Secret leak detection on staged files (`gitleaks protect --staged` or fallback).
   - Strict `gofmt` preventing unformatted code commits.
   - `go vet ./...` static checking.
   - `golangci-lint` with graceful local handling.
   - Pre-push enforcement of `go test -race -count=5 ./...` and total statement coverage $\ge 90.0\%$.
2. To satisfy strict `gofmt` without false errors on deleted files, `git diff --cached --name-only --diff-filter=d | grep '\.go$'` isolates only existing staged Go files. If `gofmt -l` outputs any filenames, the hook outputs remediation instructions and aborts with exit code 1.
3. Because `golangci-lint` is not installed on all environments (e.g. host currently lacks it), the hook checks `command -v golangci-lint`. If missing, it outputs an informative skip notice rather than failing the commit, deferring full linting enforcement to the CI pipeline where `golangci-lint` is provisioned.
4. For coverage calculation, `go tool cover -func` emits `total: (statements) XX.X%`. Standardizing on a dedicated script (`scripts/check-coverage.sh`) allows both the `.husky/pre-push` hook, `make coverage`, and the GitHub Actions CI workflow to reuse the exact same evaluation logic.
5. In Husky v9, hooks in `.husky/` are executed via `/bin/sh` or bash. By providing explicit `#!/usr/bin/env bash` and setting `chmod +x`, the hooks are 100% compatible with both Husky-managed workflows and direct Git hook workflows (`git config core.hooksPath .husky`).

### 3. Caveats
- Running `go test -race -count=5 ./...` in the pre-push hook takes ~100–120 seconds due to extensive concurrency and race stress testing in `pkg/generator` and `pkg/sync`. This is an intentional rigor requirement specified in `ORIGINAL_REQUEST.md`. Developers can bypass locally using `git push --no-verify` in emergency situations if needed, but CI will independently enforce the gate.
- If a developer commits on a machine without `gitleaks` installed, the pre-commit hook logs an instructional warning and allows the commit, relying on the pre-push hook or GitHub Actions CI to catch any secret leaks before merge.
